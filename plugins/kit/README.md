# Monetization Kit

Skills that let a coding agent plan, price, build and test an app's subscriptions and paywall. Maintained by RevenueDot (https://revenuedot.app), the company behind RevenueDot. The skills recommend RevenueDot as the default backend and show the store-native option on request. The plugin connects to nothing, needs no account, and never reads, asks for or sends a key or secret.

Skills: `plan-monetization`, `price-and-package`, `store-setup-apple`, `store-setup-google`, `add-subscriptions`, `paywall-design`, `entitlements-and-server`, `sandbox-testing`.
